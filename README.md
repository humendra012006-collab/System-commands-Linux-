## 📌 About This Repository

This repository contains notes, practice exercises, and study materials for the **System Commands** course, offered as part of the Diploma in Programming level in the IIT Madras BS Degree program.

The content covers Unix/Linux command-line interfaces, shell scripting, file manipulation, process management, and essential system administration tools taught across the 10-week curriculum.
